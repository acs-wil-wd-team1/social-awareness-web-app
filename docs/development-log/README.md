# Development log

This folder records completed development work so the team does not have to reconstruct everything when preparing the Stage 3 Developers Manual.

Create an entry only after meaningful work has been completed.

Suggested filename: `YYYY-MM-DD-feature-name.md`

Each entry should contain:

## Goal

What was being built or corrected?

## Result

What now works?

## Files changed

Which important files were added or changed?

## How it works

Explain the main flow in plain language.

## Decisions

What decisions affected the implementation?

## Checks completed

What tests, builds or manual checks were run?

## Problems and fixes

What went wrong, and how was it corrected?

## Evidence

Where are the screenshots, test results or related commits?

## Remaining work

What dependency or next action remains?

Development logs are working evidence. They are not automatically the complete Developers Manual.
