# Design handoff

The Front-end Designers can choose the design tool they are most comfortable using.

Figma is one suggestion because it supports shared files and comments. Canva can also be used for wireframes and storyboards.

## Editable design source

| Item | Tool | Source link | Status |
|---|---|---|---|
| Wireframes | To be chosen | To be added | Not started |
| Storyboards | To be chosen | To be added | Not started |
| Design standards | To be chosen | To be added | Not started |

The editable source remains in the tool selected by the designers.

## Repository exports

Once the team selects a version, dated exports can be uploaded here.

Suggested filenames:

- `wireframes/home-guest-desktop-v1.png`
- `wireframes/home-guest-mobile-v1.png`
- `wireframes/login-desktop-v1.png`
- `wireframes/registration-mobile-v1.png`
- `storyboards/authentication-journey-v1.pdf`

Each export should record its contributor, source link, export date, version, screens covered and review status.

Avoid filenames such as `final-final-new.png`.

## Suggested handoff

1. Designers choose their preferred tool.
2. Designers prepare the wireframes and storyboards.
3. The team reviews the proposed design.
4. The selected version is exported.
5. The contributor uploads the export using their own GitHub account.
6. Developers build against that version.
7. The same selected export is used in the Design Document.

The design files support the prototype. The running React application is the coded prototype.
