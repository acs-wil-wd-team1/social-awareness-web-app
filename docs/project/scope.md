# Project scope

This summary supports implementation and does not replace the submitted Project Charter.

## Product purpose

The Social Awareness Web Application gives users a platform to discover and engage with social causes. It also gives small-business owners a place to promote their businesses through campaigns.

## Stage 2 — Prototype 1

The Stage 2 running prototype contains exactly four functional areas:

1. Campaign homepage available to guests
2. Registration of a new account
3. Login
4. Logout

The frontend and backend should work against the same agreed API contract. A mock API approach can help the frontend progress while the Database Developers build the server, but the exact mocking tool still needs to be confirmed.

## Stage 2 supporting outputs

- Design Document
- Prototype Document and demonstration video
- API contract and backend-model liaison
- Class diagram and other allocated design diagrams
- Test-case design
- Cloud deployment model
- Running frontend and backend evidence supplied by the responsible roles

## Deferred to Stage 3

- Campaign creation for social causes
- Small-business campaign posting
- Campaign participation
- Administrator approval
- Live content updates
- Enhanced authentication and security agreed for the final system
- AWS EC2 deployment
- User Manual
- Developers Manual
- Testing Document

## Outside the agreed project scope

- Payments
- Direct messaging
- Analytics dashboards
- Advertising networks
- Unrelated social-network features

Any change to these boundaries should be agreed by the team and recorded through the Project Manager before implementation.
